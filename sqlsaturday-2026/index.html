13 · Do slide pro notebook
# esqueleto ilustrativo (não é o código de produção)
import numpy as np
from sklearn.cluster import DBSCAN
from joblib import Parallel, delayed

R = 6_371_000  # raio da Terra, em metros

def lugares_do_associado(pdf, eps_m=120, min_pts=5):
    xy = np.radians(pdf[["lat", "lon"]].to_numpy())
    pdf["cluster"] = DBSCAN(
        eps=eps_m / R, min_samples=min_pts,
        metric="haversine", algorithm="ball_tree",
    ).fit_predict(xy)               # -1 = ruído
    return pdf

# 1 tarefa por associado, todos os núcleos do nó
grupos = df_rs.groupby("associado_id")
partes = Parallel(n_jobs=-1)(
    delayed(lugares_do_associado)(g) for _, g in grupos)

14 · Uso 01 · Atendimento
Perdeu o celular na enchente. A agência está debaixo d'água.
O único canal que sobrou era o telefone e o WhatsApp. E os golpistas sabiam disso.
A decisão real
Como facilitar o acesso de quem foi atingido sem criar uma nova brecha de segurança?
O sinal geográfico entrou na fila de reativação do token: quem tinha centro de gravidade na área atingida ganhava prioridade, com os controles de segurança mantidos.
